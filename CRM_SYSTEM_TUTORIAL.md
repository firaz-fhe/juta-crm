## Getting Started

### First Time Setup
1. **Login**: Enter your email and password to access the CRM system
2. **Role Assignment**: Your administrator will assign you a role (1, 2, or 3) which determines your access level
3. **Company Configuration**: Ensure your company has been set up with the necessary AI assistant configurations

### System Overview
The Juta CRM system is an AI-powered customer relationship management platform that combines:
- **AI Chat Assistant**: Intelligent customer interactions
- **Follow-up Automation**: Automated message sequences
- **Contact Management**: Organized customer database
- **Analytics & Reporting**: Performance insights
- **Multi-role Access**: Different permission levels for team members

## Chat/Inbox Page

### Main Interface Layout
The Chat/Inbox page is the heart of the CRM system, featuring a two-panel layout:

#### **Left Panel - Assistant Configuration**
**Purpose**: Configure your AI assistant's behavior and knowledge base

##### **Assistant Name Field**
- **Location**: Top of left panel
- **Purpose**: Set a friendly name for your AI assistant
- **How to Use**: 
  1. Click in the text field
  2. Type a descriptive name (e.g., "Sales Assistant", "Customer Support Bot")
  3. The name will appear in chat conversations

##### **Description Field**
- **Location**: Below the name field
- **Purpose**: Provide a brief description of what your assistant does
- **How to Use**:
  1. Click in the text area
  2. Write 2-3 sentences explaining your assistant's role
  3. Example: "A helpful sales assistant that guides customers through our product selection process"

##### **Instructions Text Area** (Main Configuration)
- **Location**: Large text area below description
- **Purpose**: Define how your AI assistant should behave and respond
- **How to Use**:
  1. Click in the large text area
  2. Write detailed instructions for your assistant
  3. Include:
     - Role definition (e.g., "You are a sales assistant")
     - Tone guidelines (e.g., "Be professional but friendly")
     - Specific capabilities (e.g., "You can help with product selection")
     - Response format preferences
  4. Use the **Fullscreen Editor** button for easier editing of long instructions

##### **Fullscreen Editor Button**
- **Location**: Top-right corner of instructions text area
- **Purpose**: Open instructions in a full-screen editing mode
- **How to Use**:
  1. Click the expand icon (↗) in the top-right corner
  2. Instructions open in full-screen mode
  3. Edit your instructions with more space
  4. Click "Save Instructions" when done
  5. Click the X to return to normal view

##### **Version History Button**
- **Location**: Bottom-left of instructions text area
- **Purpose**: Access previously saved versions of your instructions
- **How to Use**:
  1. Click "Version History" button
  2. View list of saved versions
  3. Click "Load" to restore a previous version
  4. Click "Delete" to remove old versions

##### **Save Instructions Button**
- **Location**: Bottom-right of instructions text area
- **Purpose**: Save your current assistant configuration
- **How to Use**:
  1. Make changes to name, description, or instructions
  2. Click "Save Instructions" button
  3. Wait for confirmation message
  4. Your changes are now active

#### **Right Panel - Chat Interface**
**Purpose**: Interact with your AI assistant and manage customer conversations

##### **Chat Header**
- **Assistant Name Display**: Shows the current assistant's name
- **Thread Management**: Each conversation is a separate thread
- **Delete Thread Button**: Remove current conversation history

##### **Message Display Area**
- **Customer Messages**: Appear on the left with customer avatar
- **Assistant Responses**: Appear on the right with AI assistant styling
- **Message Timestamps**: Show when each message was sent
- **File Attachments**: Display documents, images, and videos

##### **Message Input Area**
- **Text Input**: Type your messages to the AI assistant
- **Send Button**: Click to send your message
- **Enter Key**: Press Enter to send, Shift+Enter for new line
- **Character Count**: Shows message length below input

##### **AI Tools Section** (When Enabled)
**Purpose**: Access pre-built AI automation tools

###### **Calendar & Reminders**
- **Purpose**: Event management and scheduling
- **How to Use**:
  1. Click "Calendar & Reminders" button
  2. View available calendar tools
  3. Click "Copy" on any tool
  4. Paste into chat to use

###### **Task Management**
- **Purpose**: Create and manage tasks
- **How to Use**:
  1. Click "Task Management" button
  2. Browse available task tools
  3. Copy and paste into chat

###### **Contact Management**
- **Purpose**: Contact and tag operations
- **How to Use**:
  1. Click "Contact Management" button
  2. View contact-related tools
  3. Copy tools to use in chat

###### **Database & Custom Fields**
- **Purpose**: Data management tools
- **How to Use**:
  1. Click "Database & Custom Fields" button
  2. Access data manipulation tools
  3. Copy tools for use

###### **Utility Functions**
- **Purpose**: Web search and date operations
- **How to Use**:
  1. Click "Utility Functions" button
  2. Access utility tools
  3. Copy tools for use

##### **Knowledge Base Section**
**Purpose**: Upload files to enhance your assistant's knowledge

###### **File Upload**
- **Supported Formats**: Documents, images, videos
- **How to Use**:
  1. Click "Choose File" button
  2. Select file from your computer
  3. File uploads automatically
  4. Progress bar shows upload status

###### **File Management**
- **View Files**: See list of uploaded files
- **Download Files**: Click file name to download
- **Delete Files**: Click "Delete" button to remove files
- **File Types**: Shows file type and size

##### **Response Delay Settings**
**Purpose**: Control how quickly your AI responds

###### **Delay Configuration**
- **Range**: 0-300 seconds
- **How to Use**:
  1. Enter number of seconds in the input field
  2. Click "Save Response Delay" button
  3. AI will wait this amount of time before responding

###### **Use Cases**:
- **0 seconds**: Instant responses
- **5-15 seconds**: Natural conversation flow
- **30+ seconds**: Simulate human typing time

## Follow-Ups Management

### Accessing Follow-Ups
1. Click "Follow-Ups" button in top navigation
2. Page opens with template management interface

### Template Management

#### **Creating New Templates**
1. **Click "Add Template" Button**
   - **Location**: Top-right of the page
   - **Purpose**: Create new follow-up sequence

2. **Template Configuration**
   - **Name**: Enter descriptive template name
   - **Trigger Tags**: Select tags that activate the sequence
   - **Trigger Keywords**: Add specific keywords to trigger sequence
   - **Start Time Options**:
     - **Immediate**: Start when tag is applied
     - **Delayed**: Start 24 hours after tag
     - **Custom**: Set specific start time

3. **Batch Settings**
   - **Contacts Per Batch**: Number of contacts to process (1-100)
   - **Message Delay**: Random delay between messages (seconds/minutes)
   - **Sleep Hours**: Set active hours for sending messages
   - **Continuous Follow-ups**: Restart sequence after completion

4. **Save Template**
   - Click "Add Template" button
   - Template appears in left sidebar

#### **Managing Existing Templates**

##### **Template List (Left Sidebar)**
- **Template Names**: Click to select and view messages
- **Creation Date**: Shows when template was created
- **Trigger Tags**: Visual display of activation tags
- **Trigger Keywords**: Shows activation keywords
- **Status**: Active/Inactive indicator

##### **Template Actions**
- **Edit Button**: Modify template settings
- **Delete Button**: Remove template (with confirmation)

#### **Message Management**

##### **Adding Messages**
1. **Select Template**: Click on template in left sidebar
2. **Message Form**: Appears in right panel
3. **Configure Message**:
   - **Day Number**: Which day in sequence (1, 2, 3, etc.)
   - **Sequence**: Order within the day (1, 2, 3, etc.)
   - **Message Content**: Type your message text
   - **Timing Options**:
     - **Delay After**: Time after previous message
     - **Scheduled Time**: Specific time to send
   - **File Attachments**: Add documents, images, or videos
   - **Tag Management**:
     - **Add Tags**: Tags to add when message is sent
     - **Remove Tags**: Tags to remove when message is sent

4. **Save Message**: Click "Add Message" button

##### **Editing Messages**
1. **Click "Edit" Button**: On any message
2. **Modify Fields**: Change any message properties
3. **Save Changes**: Click "Save Changes" button

##### **Deleting Messages**
1. **Click "Delete" Button**: On any message
2. **Confirm Deletion**: Click "OK" in confirmation dialog

##### **Message Preview**
- **Real-time Preview**: See how message will appear
- **Tag Display**: Shows tags that will be added/removed
- **Timing Information**: Displays when message will be sent

#### **Advanced Features**

##### **Batch Processing**
- **Contact Limits**: Control how many contacts receive messages
- **Delay Settings**: Natural timing between messages
- **Active Hours**: Only send during business hours

##### **Tag Automation**
- **Automatic Tagging**: Add/remove tags based on message sequence
- **Trigger Logic**: Tags activate follow-up sequences
- **Customer Segmentation**: Organize contacts by behavior

## Best Practices & Tips

### Getting the Most from Your AI Assistant

#### **Writing Effective Instructions**
1. **Be Specific**: Clearly define the assistant's role
2. **Provide Examples**: Show desired response formats
3. **Set Boundaries**: Define what the assistant should not do
4. **Use Clear Language**: Avoid ambiguous instructions
5. **Test and Iterate**: Refine instructions based on performance

#### **Creating Effective Follow-up Sequences**
1. **Start Simple**: Begin with 3-5 message sequences
2. **Test Timing**: Experiment with different delays
3. **Personalize Content**: Use customer data for relevance
4. **Monitor Performance**: Track open rates and responses
5. **Optimize Continuously**: Improve based on results

#### **Managing Your Contact Database**
1. **Regular Updates**: Keep contact information current
2. **Tag Organization**: Use consistent tagging system
3. **Segment Audiences**: Group contacts by behavior
4. **Clean Data**: Remove invalid or duplicate contacts
5. **Privacy Compliance**: Follow data protection regulations

### Troubleshooting Common Issues

#### **AI Assistant Not Responding**
1. **Check API Configuration**: Verify OpenAI API key
2. **Review Instructions**: Ensure instructions are clear
3. **Check System Status**: Verify system connectivity
4. **Contact Support**: If issues persist

#### **Follow-up Messages Not Sending**
1. **Verify Template Status**: Ensure template is active
2. **Check Trigger Conditions**: Verify tags and keywords
3. **Review Timing Settings**: Check delay configurations
4. **Monitor System Logs**: Look for error messages

#### **Performance Issues**
1. **Clear Browser Cache**: Refresh system data
2. **Check Internet Connection**: Ensure stable connectivity
3. **Restart Application**: Close and reopen browser
4. **Contact IT Support**: For persistent issues
